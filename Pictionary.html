    Comment on joue ensemble ?

    1. Le créateur ouvre la partie et partage son code.
    2. Les autres ouvrent ce même site, saisissent leur prénom et le code.
    3. Chaque dessinateur révèle le mot de la couleur choisie. Ceux qui devinent gardent les mots masqués.
    4. Le créateur lance la manche : les cartes se masquent et tous les chronos démarrent ensemble.

    Les invités peuvent lire les mots, mais ne peuvent changer ni la carte, ni la couleur, ni le chrono. Quitter la page ne ferme pas la partie ; le créateur peut la retrouver avec le même navigateur et le code.

    Le code des cartes classiques

    La flèche ► change la manche. Chaque carte contient une ou deux flèches, réparties au hasard entre le jaune, le bleu et l’orange. Elle déclenche un défi collectif. Dans cette version, les mots verts n’ont jamais de flèche et restent des tours d’équipe. En rouge, le défi est systématique, sans flèche : il ne compte pas dans la limite des deux flèches.

    Une manche en quelques gestes

    1. Choisissez la couleur de votre case, ou une couleur de votre choix si vous jouez sans plateau.
    2. Le dessinateur révèle le mot discrètement. Pour un défi, un dessinateur de chaque équipe lit le même mot.
    3. Lancez la manche : 5 secondes de préparation, puis la durée réglée pour ce type de mot. Le mot se masque automatiquement.
    4. Faites deviner avec un dessin, sans parler, mimer, écrire de lettres ou de chiffres. Décidez ensemble de la précision attendue.
    5. Lors d’un défi, la première équipe à trouver remporte la manche. Changez de dessinateur pour le mot suivant.

    Avec le plateau : après une réussite, l’équipe gagnante garde ou prend la main, lance le dé puis avance. Sans plateau, vous pouvez compter 1 point par mot trouvé : c’est une variante maison.
